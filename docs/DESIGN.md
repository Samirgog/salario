# Salario design

Выбрано направление «тёплый ретро-футуризм / неоново-кассетный». Семейные расходы должны ощущаться не бухгалтерией, а живым совместным «кассетным» планом: чернильный фон, кислотный лайм для действий, коралловый для внимания и голубой для накоплений. Карточки напоминают фрагменты чека, а период выплат — ленту билетов.

Токены находятся в `src/styles.css`. Главный принцип: цвет сообщает смысл — лайм означает действие и доступность, коралл — необходимость внимания, голубой — долгосрочную цель. В будущих итерациях шрифты можно заменить на локальные файлы без изменения компонентов.
