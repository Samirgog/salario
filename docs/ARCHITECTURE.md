# Архитектура

Клиент — React 18 + TypeScript strict + Vite. `src/domain` содержит чистую payday-логику без доступа к UI и БД. Серверные данные должны поступать из Supabase; UI не содержит демонстрационных записей и показывает empty states до первого действия пользователя. HashRouter следует добавить при расширении маршрутов, сейчас вкладки не меняют URL, чтобы стартовый экран был компактным.

JWT Telegram должен выдаваться Edge Function после проверки `initDataRaw`; service-role ключ не попадает в клиент. Все пользовательские строки привязаны к `household_id` и закрыты RLS.
