# Salario

Telegram Mini App для совместного планирования расходов между выплатами 5-го и 20-го числа. Проект намеренно не содержит seed/mock-данных: после авторизации и настройки Supabase пользователь видит пустые состояния и заполняет пространство сам.

Подробная установка — в [SETUP.md](SETUP.md). Дизайн описан в [docs/DESIGN.md](docs/DESIGN.md).
